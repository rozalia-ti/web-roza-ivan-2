# Лабораторная работа №2

REST API для системы управления студентами общежития на FastAPI.
Клиентский интерфейс работает в режиме stateless — бизнес-логика перенесена на сервер.
Фронтенд — чистый JavaScript без фреймворков.

Возможности:
- просмотр списка студентов;
- добавление, редактирование и удаление студентов;
- просмотр досье студента;
- фильтрация списка по свойствам студента (по вхождению, применяется при вводе);
- серверная валидация данных (Pydantic);
- уникальный ИСУ ID;
- хранение данных в JSON-файле.

Запуск:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --port 8000
```

После запуска открыть в браузере:

```text
http://localhost:8000
```

Запросы API:
- `GET /api/requests` — список студентов, фильтрация через query-параметры (`?group=P32&dormitory=8`);
- `GET /api/requests/:id` — студент по идентификатору;
- `POST /api/requests` — добавление студента;
- `PATCH /api/requests/:id` — частичное обновление студента;
- `DELETE /api/requests/:id` — удаление студента;
- `QUERY /api/requests/:id` — запрос студента по идентификатору.

Основные файлы:
- `app/main.py` — точка входа, единый формат ошибок, раздача статики;
- `app/routes.py` — маршруты API;
- `app/services.py` — бизнес-логика;
- `app/storage.py` — работа с данными (JSON-файл);
- `app/schemas.py` — модели Pydantic;
- `static/` — клиентский интерфейс;
- `data.json` — хранилище студентов.
