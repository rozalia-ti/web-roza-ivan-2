# Лабораторная работа №1

Приложение для управления студентами без фреймворков

Возможности:
- просмотр списка студентов;
- добавление, редактирование и удаление студентов;
- просмотр досье студента;
- проверка данных формы;
- хранение данных в IndexedDB браузера.

Запуск:

```bash
python3 -m http.server 8000
```

После запуска открыть в браузере:

```text
http://localhost:8000
```

Основные файлы:
- `index.html` — главная страница с таблицей;
- `student-form.html` — шаблон формы, который JavaScript добавляет в страницу;
- `student-details.html` — шаблон досье;
- `style.css` — стили;
- `index.js` — логика интерфейса;
- `db.js` — работа с IndexedDB;
- `validation.js` — проверка формы.
